Hotel Manager

Hotel Manager is a Property Management System (PMS) developed with Django.

The project allows hotel staff to manage rooms, guests, and reservations while monitoring hotel occupancy through an interactive dashboard and an availability page.

Technologies

- Python
- Django
- SQLite
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

Features

Dashboard
- Total number of rooms
- Available rooms
- In-house guests
- Daily check-ins
- Daily check-outs
- Occupancy rate

Room Management
- Create rooms
- Edit room information
- Search rooms
- Room status management:
  - Clean
  - Dirty
  - Inspected
  - Blocked
  - Occupied

Guest Management
- Create guests
- Edit guest information
- Search guests

Reservation Management
- Create reservations
- Edit reservations
- Cancel reservations
- Search by reservation ID or guest
- Automatic assignment of available rooms
- Prevents double bookings

Availability
- Check room availability for any date range
- Availability by room type
- Supports reservations without an assigned room
- Detects overbooking

User Interface
- Light/Dark mode
- Responsive design
- Simple and intuitive navigation
